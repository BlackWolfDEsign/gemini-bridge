# gemini – Gemini als Recherche- und Design-Partner

Claude Code delegiert Recherchen, Tiefenrecherchen mit Red-Team-Gegenprüfung, Design-Entwürfe und Zweitmeinungen an Gemini – über die Google Antigravity CLI (agy) und dein Google-AI-Abo, ohne API-Key. Befehle: /gemini:frage, /gemini:recherche, /gemini:tiefenrecherche, /gemini:design, /gemini:zweitmeinung, /gemini:setup, dazu /gemini:app für die Gemini-App über Claude in Chrome (nur auf Wunsch). Claude nutzt sie auch selbstständig. Gemini sieht dein Projekt nicht, Aufrufe laufen nacheinander. Voraussetzung: agy installiert und einmal angemeldet. Ausführliche Anleitung in der README im Hauptordner.
